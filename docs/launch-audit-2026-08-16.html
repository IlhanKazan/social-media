Correction, 16 Aug. An earlier version of this page reported robots.txt, sitemap.xml and llms.txt as present. They are not. The first check trusted the HTTP status, and the SPA catch-all answers 200 for every unknown path — the same soft-404 defect listed further down. Re-checked by content type: all three return the HTML shell. Only favicon.ico and site.webmanifest are real files.
Headline: the security posture is genuinely strong — HSTS, CSP, rate limiting, BCrypt, audit logging, upload whitelisting and correct cookie flags are all live and verified. The gaps cluster in two places that cost almost nothing to fix: DNS records (five missing, all registrar-side) and SEO plumbing, which turns out to be nearly untouched once the soft-404 stops masking it.

Do these first highest value, lowest effort

Ordered by payoff per minute spent. All five are yours to action — no code from me.

ItemWhy it mattersWhere
SPF recordYou send real mail through Resend. With no SPF, receivers have nothing to check the sender against — verification and reset mail lands in spam.Registrar
DMARC recordWithout it anyone can spoof your domain. Start at p=none to collect reports, then move to p=reject.Registrar
Soft 404/any-missing-path returns 200. Search engines index junk URLs as real pages — and it hid three missing files from this very audit.nginx / Cloudflare
robots.txt + sitemap.xmlNeither exists. Two static files in public/; the sitemap can be generated at build time from the route table.client/public
CAA recordAny public CA can currently issue a certificate for the domain. One line pins it to your issuer.Registrar
Canonical tagMissing entirely. Duplicate-URL variants compete with each other in search results.index.html

DNS all five verified empty

Checked with dig against the live zone. Every one came back empty. These are the cheapest wins on the whole list: registrar-side, no deploy, no code.

RecordStatusPublish
SPFMissingA TXT record ending in -all, listing Resend. Mind the 10-lookup limit.
DMARCMissing_dmarc TXT. Begin p=none with a rua= address, tighten to p=reject once reports look clean.
CAAMissingPin issuance to your CA and forbid wildcards.
DNSSECMissingNo DS record at the parent. Cloudflare signs the zone, but it does nothing until the DS is published at the registrar.
MTA-STSMissingOptional at this scale. Needs a TXT record and a hosted policy file — skip until mail volume justifies it.
The trap in this list: having a record and enforcing it are different states. p=none, ~all and MTA-STS mode=testing all look configured and block nothing.

Post-launch your call, not blockers

Search Console, GA4, conversion tracking, heatmaps, A/B tests, review collection and email capture are all growth instrumentation. For a portfolio piece, only two earn their keep: Search Console (free, tells you whether Google can actually read a client-rendered SPA — a genuinely useful signal here) and image compression, which is a real performance win. The rest optimise conversions this project is not chasing.
